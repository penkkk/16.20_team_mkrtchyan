# Vision — ITLib

## 1. Vision statement

Для студентов и начинающих IT-специалистов, которым нужно быстро находить
профессиональную литературу и получать к ней понятный доступ, ITLib —
это учебная электронная библиотека IT-книг по подписке. Она помогает выбирать
материалы по технологии, уровню подготовки и учебной цели, а также прозрачно
показывает доступ к чтению. В отличие от универсальных книжных сервисов и
платформ со статьями, ITLib специализируется на профессиональной IT-литературе,
тематических подборках и маршрутах обучения.

## 2. Целевая аудитория

| Роль | Цель использования |
| --- | --- |
| Читатель ( авторизированный пользователь ) | Найти подходящую книгу, проверить доступ и читать её. |
| Администратор | Добавлять карточки и PDF-файлы книг, контролировать доступность, просматривать аналитику по книгам, пользователям и подпискам. |
| Гость | Просматривает каталог и подборки, но не читает книги без подписки. |

## 3. Границы системы

### Входит в систему

- каталог IT-книг;
- поиск по названию и автору, фильтры по технологии и уровню;
- карточка книги;
- статус подписки и доступ к чтению;
- личная библиотека;
- тематические подборки;
- загрузка и чтение книг в формате PDF;
- оплата подписки через платёжную систему (реальная интеграция, тестовые платежи);
- аналитика для администратора: информация о пользователях, их подписках, данные о популярных книгах.

### Не входит в систему
- лицензирование контента;
- интеграции с издателями;
- физическая выдача книг, возвраты, штрафы и просрочки.
