# Трассируемость требований

Таблица связывает требования электронной библиотеки с компонентами архитектуры, которые обеспечивают их реализацию.

| ID | Требование | Архитектурный компонент |
|---|---|---|
| TR_01 | Регистрация и вход по электронной почте | Модуль авторизации, база пользователей |
| TR_02 | Вход через Яндекс и Google | Модуль OAuth-интеграций |
| TR_03 | Отображение топа книг за неделю | Модуль аналитики просмотров, главная страница |
| TR_04 | Поиск по названию, автору и смыслу | Поисковый модуль, каталог книг, поисковый индекс |
| TR_05 | Каталог с фильтрами | Модуль каталога, база книг |
| TR_06 | Рекомендации книг | Модуль рекомендаций |
| TR_07 | Онлайн-чтение и скачивание | Модуль доступа к книгам, файловое хранилище |
| TR_08 | Личная библиотека пользователя | Профиль пользователя, база пользовательских данных |
| TR_09 | Покупка подписки | Модуль подписок, интеграция с платёжной системой |
| TR_10 | Добавление книг администратором | Админ-панель, модуль управления каталогом |
