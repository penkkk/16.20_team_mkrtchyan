# Анализ рынка и аналогов — ITLib

## 1. Описание продукта

**ITLib** — учебная онлайн-библиотека профессиональной IT-литературы по
подписке. Пользователь ищет книгу по технологии, автору или названию, видит
её карточку и получает доступ к чтению при активной подписке. В рамках MVP
подписка моделируется статусом доступа: реальные платежи, лицензирование
контента и интеграции с издателями не реализуются.


## 2. Аналоги

| Тип | Аналог | Почему выбран | Что берём в ITLib 
| --- | --- | --- | --- |
| Прямой | [O'Reilly Learning](https://www.oreilly.com/online-learning/) | Сервис даёт доступ к техническим книгам, курсам и материалам для развития профессиональных навыков. | Фокус на IT-знаниях; распределение уровня сложности; поиск; тематическая классификация; качественные подборки для конкретной цели обучения. 
| Косвенный | [Habr](https://habr.com/en/docs/help/hubs/) | Пользователь решает ту же задачу — осваивает IT-темы, но через статьи, сообщества и публикации, а не через библиотеку книг. | Дерево технологических тем, теги, фильтрацию и переход от интереса пользователя к тематической подборке. 
| Референсный | [Яндекс Книги](https://books.yandex.ru/) | Не является ориентиром по IT-контенту, но показывает понятную потребительскую модель чтения по подписке. | Видимый статус подписки; личную библиотеку; тематические полки/подборки; единый сценарий «выбрать → получить доступ → читать».

## 4. Метод: инсайт → потребность → требование → критерий

| Этап | Формулировка | Результат |
| --- | --- | --- |
| Инсайт | Начинающему специлисту в области IT сложно выбрать одну полезную книгу среди множества всего каталога. | Нужна навигация по темактике, технологиям, уровню сложности и учебным целям. |
| Потребность | Быстро находить литературу по конкретной теме, технологии и уровню подготовки. | Пользователь может искать по названию и автору, тексту, а также фильтровать по технологии и уровню. |
| Требование | Система показывает каталог книг с полями: название, автор, технология, уровень, описание, обложка. Система предоставляет поиск по тексту, автору, названию и фильтры по технологии/уровню. | Экран каталога и экран результата поиска. |
| Критерий | Пользователь находит книгу «Чистый код» по названию или выводит подборку «Python для начинающих» фильтром по теме и уровню. | Проверка в демонстрационном сценарии. |

| Этап | Формулировка | Результат |
| --- | --- | --- |
| Инсайт | Администратор добавляет книгу по одной, но читатель часто ищет не точное название, а ответ на учебную задачу: например, «как изучить Docker» или «паттерны проектирования». Обычный поиск только по названию и автору не находит подходящие книги надёжно. | Нужна карточка загрузки одной книги и поиск по содержанию. |
| Потребность | Добавить книгу без ручной разметки всего текста и позволить читателю находить материалы по смыслу запроса. | После загрузки система автоматически обрабатывает книгу и создаёт поисковый индекс. |
| Требование | Администратор создаёт карточку книги и загружает файл PDF/EPUB. Исходный файл сохраняется в S3-совместимом хранилище; в PostgreSQL сохраняются метаданные и ключ объекта.  Система извлекает текст, делит его на фрагменты, строит для каждого фрагмента эмбеддинг и сохраняет эмбеддинги в PostgreSQL с расширением pgvector. | Форма добавления одной книги; статусы обработки; таблицы для книг и векторов. |
| Критерий | Администратор загружает одну корректную книгу и получает статус успешно. Запрос «как изучить Docker» возвращает книгу или её фрагмент, где Docker описывается, даже если слово не указано в названии. При неверном формате или ошибке обработки книга получает статус незавершено, а исходный файл не становится доступен читателю. | Проверка в демонстрационном сценарии |
