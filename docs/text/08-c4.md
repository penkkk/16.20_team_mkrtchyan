# C4-модель электронной библиотеки

Документ описывает архитектуру электронной библиотеки на трёх уровнях C4:

1. **System Context** — место системы среди пользователей и внешних сервисов.
2. **Container** — крупные приложения и хранилища, из которых состоит система.
3. **Component** — модули Backend, Search Service и контура отчётности и их взаимодействия.

## Уровень 1. System Context

![System Context Diagram](../schemas/System%20Context%20Diagram.png)

Диаграмма показывает электронную библиотеку как единую программную систему. Она позволяет пользователям искать, читать и скачивать книги, добавлять их в избранное, управлять профилем и оплачивать подписку.

### Участники и внешние системы

| Элемент | Тип C4 | Ответственность или связь с системой |
|---|---|---|
| Гость | Person | Ищет и просматривает книги без авторизации. |
| Читатель | Person | Читает книги и управляет своим профилем. |
| Администратор | Person | Модерирует контент и добавляет книги. |
| Аналитик | Person | Формирует отчёты по книгам, пользователям и подпискам. |
| Электронная библиотека | Software System | Предоставляет функции каталога, чтения, скачивания, профиля и подписки. |
| Yandex ID | External System | Предоставляет OAuth-авторизацию через Яндекс. |
| Google | External System | Предоставляет OAuth-авторизацию через Google. |
| Платёжная система | External System | Обрабатывает и подтверждает оплату подписки. |

### Связи

| Источник | Получатель | Назначение связи |
|---|---|---|
| Гость | Электронная библиотека | Поиск и просмотр книг. |
| Читатель | Электронная библиотека | Чтение книг и управление профилем. |
| Администратор | Электронная библиотека | Добавление и модерация книг. |
| Аналитик | Электронная библиотека | Формирование отчётов. |
| Электронная библиотека | Yandex ID, Google | OAuth-авторизация. |
| Электронная библиотека | Платёжная система | Создание и проверка платежей за подписку. |

## Уровень 2. Container

![Container Diagram](../schemas/Container%20Diagram.png)

Контейнерная диаграмма раскрывает внутреннее устройство электронной библиотеки. Каждый контейнер представляет отдельное приложение, сервис или хранилище данных.

### Контейнеры системы

| Контейнер | Технология | Назначение |
|---|---|---|
| UI | React SPA, Nginx | Отдаёт пользователю веб-интерфейс электронной библиотеки. |
| Reverse Proxy | Traefik | Принимает входящий HTTP-трафик, обнаруживает сервисы и перенаправляет запросы в UI, панели мониторинга и S3-консоль. |
| Backend | Go, Gin Gonic | Обрабатывает API-запросы, бизнес-логику, авторизацию, работу с книгами и подписками. |
| Message Broker | RabbitMQ | Передаёт задачи на обработку книг и отправку уведомлений. |
| Search Service | bge-m3, Go | Выполняет семантический поиск и индексирует новые файлы. |
| Database | PostgreSQL | Хранит пользователей, книги, логи авторизации и векторы чанков для поиска. |
| Database | Redis | Кэширует часто используемые запросы и временные данные. |
| Bucket | Garage S3 Bucket | Хранит файлы электронных книг. |
| Monitoring System | Prometheus | Собирает метрики со всех сервисов. |
| Monitoring Dashboard | Grafana | Показывает метрики и графики мониторинга. |
| Reverse Proxy Dashboard | Traefik Dashboard | Предоставляет интерфейс для мониторинга графика reverse proxy. |
| S3 Web UI | Garage Web UI | Предоставляет интерфейс управления Garage S3. |
| Контур отчётности | 1С | Формирует административные отчёты по данным библиотеки. |

### Основные связи контейнеров

| Источник | Получатель | Взаимодействие |
|---|---|---|
| Пользователь | Reverse Proxy | Направляет HTTP-запросы к системе. |
| Reverse Proxy | UI | Перенаправляет запросы к пользовательскому интерфейсу. |
| UI | Backend | Отправляет API-запросы в формате JSON по HTTP. |
| Backend | PostgreSQL | Читает и сохраняет прикладные данные по протоколу PostgreSQL. |
| Backend | Redis | Читает и записывает кэш. |
| Backend | Garage S3 Bucket | Сохраняет и получает книги по S3 API через HTTPS. |
| Backend | Message Broker | Помещает задачи поиска и уведомлений в очередь. |
| Search Service | Message Broker | Получает задачи на индексирование. |
| Search Service | PostgreSQL | Читает и сохраняет векторы поиска. |
| Backend | Search Service | Выполняет запросы семантического поиска по gRPC. |
| Backend | Yandex ID, Google | Выполняет OAuth-авторизацию. |
| Backend | Платёжная система | Создаёт и проверяет платежи за подписку. |
| Monitoring System | Контейнеры электронной библиотеки | Собирает метрики сервисов. |
| Monitoring Dashboard, Reverse Proxy Dashboard, S3 Web UI | Reverse Proxy | Доступны через маршрутизацию Traefik. |
| Аналитик | Контур отчётности | Формирует административные отчёты. |
| Контур отчётности | PostgreSQL | Получает данные для анализа и отчётов. |

## Уровень 3. Component

![Component Diagram](../schemas/Component%20Diagram.png)

Компонентная диаграмма уточняет границы ответственности внутри контейнеров. Входящие запросы проходят через `Reverse Proxy` к UI и Backend API. Асинхронные задачи передаются через RabbitMQ, а отчётность строится в отдельном контуре 1С на данных PostgreSQL.

### Компоненты Backend API

| Компонент | Назначение | Основные зависимости |
|---|---|---|
| Payment API | Принимает запросы на оплату подписки. | Платёжная система. |
| Auth API | Регистрирует, авторизует и возвращает данные текущего пользователя. | Auth Component, OAuth Adapter, PostgreSQL, Google, Yandex ID. |
| Catalog API | Возвращает список книг, результаты поиска и карточку книги. | Catalog Component, Search Component, PostgreSQL. |
| Read API | Принимает запрос на открытие книги. | Book Access Component, Garage S3. |
| Upload API | Принимает карточку и файл книги от администратора. | Book Component, Garage S3. |
| Auth Component | Проверяет учётные данные и управляет сессиями; работает с PostgreSQL и Redis. | OAuth Adapter, PostgreSQL, Redis. |
| OAuth Adapter | Инкапсулирует обмен кодом авторизации с OAuth-провайдерами. | Google, Yandex ID. |
| Catalog Component | Хранит в PostgreSQL информацию о книгах, авторах, рейтинге и тематических тегах. | PostgreSQL. |
| Search Component | Отправляет запрос поиска в сервис поиска. | Search Service. |
| Book Access Component | Запрашивает права доступа и выдаёт файл книги из Garage S3. | PostgreSQL, Garage S3. |
| Book Component | Сохраняет карточку и файл книги. | PostgreSQL, Garage S3. |

### Компоненты Search Service

| Компонент | Назначение | Основные зависимости |
|---|---|---|
| Message Reader | Получает из очереди задачи индексации. | RabbitMQ, Indexing Component. |
| Indexing Component | Индексирует содержимое загруженной книги. | Garage S3, Embedding Component, PostgreSQL. |
| Embedding Component | Преобразует текст в векторы с помощью модели `bge-m3`. | PostgreSQL. |
| Search API | Принимает запросы семантического поиска от Backend. | Search Component. |
| Search Component | Выполняет семантический поиск по векторам чанков. | PostgreSQL. |

### Контур отчётности

| Компонент | Назначение | Основные зависимости |
|---|---|---|
| Справочник «Книги» | Содержит карточки книг с названием, автором, технологией доступа и источником данных для отчёта. | PostgreSQL. |
| Форма отчёта | Задаёт фильтр, формирует таблицу и рассчитывает результат. | Справочник «Книги», Отчёт по книгам. |
| Отчёт по книгам | Читает данные с хранением и формирует таблицу результатов. | Справочник «Книги». |

### Ключевые сценарии взаимодействия компонентов

| Сценарий | Последовательность |
|---|---|
| Авторизация | `Auth API → Auth Component → OAuth Adapter → Google / Yandex ID`; сведения о пользователе и сессии сохраняются в PostgreSQL и Redis. |
| Загрузка книги | `Upload API → Book Component → PostgreSQL + Garage S3`; задача индексации публикуется в RabbitMQ. |
| Индексация | `RabbitMQ → Message Reader → Indexing Component → Embedding Component → PostgreSQL`. |
| Поиск | `Catalog API → Search Component Backend → Search API → Search Component Search Service → PostgreSQL`; каталог возвращает пользователю результат. |
| Чтение | `Read API → Book Access Component → PostgreSQL + Garage S3`; после проверки доступа пользователю выдаётся файл. |
| Отчёт | `Аналитик → 1С → Форма отчёта → Отчёт по книгам / Справочник «Книги» → PostgreSQL`. |

### Легенда

| Обозначение на диаграммах | Значение |
|---|---|
| Зелёный элемент с силуэтом человека | Пользователь или роль пользователя. |
| Синий элемент внутри границы системы | Внутренний контейнер или программная система электронной библиотеки. |
| Оранжевый элемент за границей системы | Внешний сервис, за который команда не отвечает. |
| Цилиндр | База данных. |
| Корзина | Объектное файловое хранилище S3. |
| Пунктирная стрелка | Направленное взаимодействие; подпись описывает действие или протокол. |
