# Use case электронной библиотеки

## Акторы

| Актор | Тип | Роль и доступ |
|---|---|---|
| Гость | Первичный | Открывает главную, каталог, поиск, рекомендации и карточки книг; регистрируется или входит в систему. |
| Читатель | Первичный | Читает и скачивает книги, ведёт личную библиотеку, покупает подписку. |
| Администратор | Первичный | Добавляет электронные книги через админ-панель. |
| Аналитик | Первичный | Формирует отчёты в модуле 1С:Отчётность. |
| Администратор 1С | Первичный | Настраивает шаблоны, расписание и права доступа к отчётам. |
| Яндекс ID | Вторичный | Подтверждает вход или регистрацию через Яндекс. |
| Google | Вторичный | Подтверждает вход или регистрацию через Google. |
| Платёжная система | Вторичный | Принимает оплату подписки и сообщает её результат. |

## Подробные сценарии

### UC_1. Регистрация или вход по электронной почте

| Элемент | Описание |
|---|---|
| Предусловие | Гость находится на странице регистрации или входа. |
| Основной поток | 1. Гость выбирает регистрацию или вход по почте.<br>2. Вводит email и пароль.<br>3. Система проверяет корректность данных.<br>4. При регистрации создаёт учётную запись; при входе авторизует пользователя.<br>5. Пользователь перенаправляется в личный профиль. |
| Постусловие | Пользователь авторизован; при регистрации создана новая учётная запись. |

### UC_2. Регистрация или вход через Яндекс / Google

| Элемент | Описание |
|---|---|
| Предусловие | Гость находится на странице регистрации или входа. |
| Основной поток | 1. Гость выбирает «Войти через Яндекс» или «Войти через Google».<br>2. Система перенаправляет его к выбранному провайдеру.<br>3. Гость подтверждает доступ.<br>4. Провайдер передаёт данные пользователя системе.<br>5. Система создаёт или находит учётную запись и авторизует пользователя. |
| Постусловие | Пользователь авторизован в электронной библиотеке. |

### UC_3. Просмотр главной страницы и топа книг недели

| Элемент | Описание |
|---|---|
| Предусловие | Пользователь открыл сайт. |
| Основной поток | 1. Пользователь переходит на главную страницу.<br>2. Система отображает топ книг по количеству просмотров за неделю.<br>3. Пользователь выбирает интересующую книгу. |
| Постусловие | Пользователь может перейти в карточку выбранной книги. |

### UC_4. Поиск книги

| Элемент | Описание |
|---|---|
| Предусловие | Пользователь находится на странице сайта. |
| Основной поток | 1. Пользователь вводит запрос в поисковую строку.<br>2. Система выполняет поиск по названию, автору и смысловому содержанию.<br>3. Система выводит подходящие книги.<br>4. Пользователь открывает карточку выбранной книги. |
| Постусловие | Пользователь получил результаты поиска или сообщение, что книги не найдены. |

### UC_5. Просмотр каталога с фильтрами

|---|---|
| Предусловие | Пользователь открыл каталог. |

| Постусловие | В каталоге отображаются книги, соответствующие выбранным фильтрам. |

### UC_6. Просмотр рекомендаций

| Постусловие | Пользователь переходит к карточке рекомендованной книги. |

### UC_7. Просмотр карточки книги

| Элемент | Описание |

| Постусловие | Пользователь получил сведения о книге и может перейти к работе с ней. |

| Постусловие | Читатель видит свои сохранённые, открытые или прочитанные книги. |

### UC_9. Чтение книги онлайн

## Содержание use case диаграммы

На диаграмме показаны два контура: «Электронная библиотека» и «1С: Отчётность». Внутри каждого контура размещаются относящиеся к нему use case, снаружи — акторы.

Связи акторов со сценариями:

| Актор | Связанные use case |
|---|---|
| Гость | UC_1–UC_7 |
| Читатель | UC_8–UC_11, UC_13 |
| Администратор | UC_12 |
| Аналитик | UC_14 |
| Администратор 1С | UC_17–UC_19 |
| Яндекс ID | UC_2 |
| Google | UC_2 |
| Платёжная система | UC_11 |

Связи между use case:

| Основной сценарий | Связь | Включаемый сценарий |
|---|---|---|
| UC_9 «Читать книгу онлайн» | «include» | Проверить доступ к книге |
| UC_10 «Скачать книгу» | «include» | Проверить доступ к книге |
| UC_11 «Купить подписку» | «include» | Оплатить подписку |
| UC_15 «Экспортировать отчёт» | «extend» | UC_14 «Сформировать отчёт в 1С» |
| Фильтровать по жанру | «extend» | UC_5 «Просмотреть каталог с фильтрами» |
| Фильтровать по автору | «extend» | UC_5 «Просмотреть каталог с фильтрами» |
| Фильтровать по языку | «extend» | UC_5 «Просмотреть каталог с фильтрами» |

На диаграмме не показываются таблицы базы данных, API, сервер, алгоритм смыслового поиска и подсчёт просмотров: это относится к ERD, C4 или технической документации.
