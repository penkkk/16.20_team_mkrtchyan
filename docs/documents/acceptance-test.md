# Приемочные проверки

| ID | Что проверяем | Ожидаемый результат | Кто | Статус |
|----|---------------|---------------------|-----|--------|
| M-4–M-6 | Открыть карточку опубликованной книги под аккаунтом без активной подписки и под аккаунтом с активной подпиской | Карточка доступна обоим. Без активной подписки кнопка «Читать» скрыта, прямой запрос полного текста отклоняется. С активной подпиской кнопка видна и открывает книгу. В профиле отображается статус подписки. | | |
| NAV-01 | Перейти по адресу недоступной пользователю страницы и по несуществующему адресу | В обоих случаях отображается сообщение об ошибке. Ссылка «На главную» открывает главную страницу. | | |
