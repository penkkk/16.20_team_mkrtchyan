# Порядок выполнения и критический путь

План охватывает все задачи Must и Should за четыре итерации. Could остаётся в резерве. Порядок рассчитан по предшественникам и оценкам из [списка задач](work-packages-tasks.md), с учётом распределения из [плана итераций](iteration-plan.md).

**Критический путь полного плана — 65 ч.** OPS-01 → OPS-04 → BE-01 → BE-03 → BE-04 → BE-05 → BE-06 → BE-07 → BE-08 → BE-12 → SUB-01 → SUB-02 → INT-02 → INT-03 → REP-02 → QA-02 → QA-03.
